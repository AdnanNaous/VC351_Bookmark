# VC351 Bookmark

A lightweight, responsive bookmark directory with **176 curated links**, organized into **5 sections** and **23 folders**.

**Live website:** https://vc351-bookmark.vc351.workers.dev/

## Features

- Minimal black-and-white layout with sharp rectangular cards
- Instant, client-side search across bookmark names, categories, and URLs
- Collapsible sections and organized folders
- Mobile-friendly responsive design
- Static HTML, CSS, and JavaScript; no database, dependencies, or build step
- Free static hosting compatible with Cloudflare

## Run locally

Download or clone this repository, then open `index.html` in your browser. No installation is required.

## Deployment

The site can be hosted using Cloudflare's static-site hosting or another static web host. Deploy `index.html` as the site's entry point.

> The live site may need to be redeployed separately after future GitHub changes. This repository is not automatically connected to Cloudflare.
